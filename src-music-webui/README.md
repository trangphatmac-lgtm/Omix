# Omix Music WebUI

This is a deliberately scoped adaptation of YesPlayMusic commit
`df075cca247eab7bf8686155cb8cc9a1f4c7e271` for the Omix JCEF WebUI.

It keeps the Vue 2 visual player, hash navigation, QR login, discovery,
search, playlist/album/artist pages, queue, lyrics, volume and theme support.
Electron, PWA, telemetry, MV, Last.fm, cloud disk, unblocking and persistent
audio-cache integrations are intentionally excluded.

The original YesPlayMusic MIT license is retained in `LICENSE`; aggregate
notices are maintained in the Omix root `THIRD_PARTY_NOTICES.md`.
